# Курс «Углублённый SQL» (28 ак. ч.)

СУБД: **PostgreSQL 16 — Yandex Managed Service for PostgreSQL**.
Аудитория: студенты старших курсов, специальность «Системный анализ».

Сквозной сюжет: компания-производитель продуктов питания **«Питание +»** переходит к управлению
на основе данных. Две команды аналитиков ищут, где компания теряет деньги:

* **Команда А — «Финансы и продажи»**
* **Команда Б — «Производство и закупки»**

Описание легенды, учебной БД (схема `pitanie`) и подключения — в [common/README.md](common/README.md).

## Быстрый старт преподавателя

```bash
pip install psycopg2-binary
export PGHOST=<адрес_сервера>   # параметры выдаёт администратор стенда
export PGUSER=<логин>
export PGPASSWORD=<пароль>
python common/scripts/run_sql.py -f common/scripts/01_create_schema.sql
python common/scripts/run_sql.py -f common/scripts/02_insert_data.sql
```

Ключи к «точкам потерь», заложенным в данные: [common/instructor_insights.md](common/instructor_insights.md)
(не раздавать слушателям).
